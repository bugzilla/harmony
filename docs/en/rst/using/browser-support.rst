Supported Browsers
##################

Bugzilla is developed and tested against current desktop web browsers.

Full support
============

* The current release of Firefox, including the latest Firefox Extended
  Support Release (ESR)
* The current release of Chrome and other Chromium-based browsers, such as
  Microsoft Edge
* The current release of Safari

Limited support
===============

* The previous release of each browser listed above, including the previous
  Firefox ESR
* Pre-release builds, such as Firefox Nightly

Bugzilla should work in these browsers, but problems that occur only in them
may not be fixed.

Not supported
=============

Internet Explorer is not supported. Some pages may still work in it, but no
fixes are made for it.

JavaScript
==========

JavaScript must be enabled for Bugzilla to work fully. Some pages work without
it, but many features, including the bug page, depend on it.
